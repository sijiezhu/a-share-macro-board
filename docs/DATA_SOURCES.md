# 数据源、字段与验证结果

本文件是数据口径的唯一说明处。采集代码中的来源、接口、字段必须与本文件一致；
任何口径变更都必须同时修改 `macroboard/config.py` 与本文件，禁止静默切换。

所有请求都是公开只读接口，不需要付费账号，不绕过任何权限限制。除妙想 API Key 外
不需要任何凭证；凭证只放在环境变量 `.env` 中，不写入代码、日志或数据库。

### 口径细节

- **美国10年期**：恒定期限名义收益率（Par Yield），不是 TIPS 实际收益率，不是票面利率。
- **中债10年期**：中债国债收益率曲线 10 年期到期收益率。不使用国开债，不使用单只债券报价。
- **美元兑人民币**：在岸 CNY 即期，取日线收盘；不使用中间价（`USDCNYC`），不使用离岸 `USD/CNH`。
  新浪日线字段顺序为 `日期, 开盘, 最低, 最高, 收盘`，本项目取收盘字段（经样本校验）。
- **黄金**：LBMA Gold Price PM 定盘价，报价时点 15:00 伦敦时间（Europe/London），
  日线边界为伦敦交易日，周末与英国假日无报价。这是现货定盘参考价，不是期货价
  （COMEX 的 `GC00Y` 未被使用）。
- **A股情绪参考**：只有两项（上涨家数占比、沪深300近20个交易日涨跌幅），不生成综合评分，
  不是官方情绪指数。上涨家数占比分母为 `上涨+下跌+平盘`，包含平盘、排除停牌与无有效涨跌幅股票。
- **沪深300 PE-TTM**：使用供应商（东方财富妙想）计算口径，未用成分股 PE 简单平均替代。
- **不同市场的数据日期允许不同**，页面逐卡片展示各自的数据日期，不强行统一为同一天。
- **A股情绪输入字段**（供 `macroboard/sentiment` 使用）：
  - `amount` / `volume`：妙想 `成交额(合计)` / `成交量(合计)`，单位分别为元与股，不做单位换算；
  - `turnover_rate`：妙想两市A股换手率，**口径按总股本**（分母为总股本，不是自由流通市值；
    2026-09-19 确认）。总股本口径的换手率数值通常低于自由流通市值口径，
    因此不要与本文件以外的其他换手率序列直接比较；若日后改口径，
    必须同时修改此处与 `macroboard/config.py` 的 `turnover_rate` 说明；
  - `margin_net_buy`：**由融资买入额与融资偿还额在同一数据日期相减得到**，
    只保留两侧都有观测的交易日，缺单侧整条丢弃，**不做前向填充、不做插值**（与股债利差同口径）；
    两融数据 **T+1 公布**，情绪算法按 `availability_lag=1` 使用（t 日只用 ≤ t−1 的观测），
    该值为有符号金额，可为负；
  - `limit_up_count` / `limit_down_count`：妙想涨停/跌停家数，家数口径由供应商给定，
    本项目不做涨跌停判定复算；
  - `pcr` / `implied_volatility`：**未接通**（见第四节），情绪算法按「不可用」跳过对应分量，
    方向指数用剩余分量计算并标注覆盖率。

## 三、计算口径

```
spread = 1 / PE_TTM - 中国10年期国债收益率
```

- 收益率统一按小数计算；PE=12.5、国债收益率=2.00% → spread = 0.06 = 6.00 个百分点 = 600 BP。
- 两个输入必须对应**同一个数据日期**，取最近一个双方均有有效数据的共同日期，并显示该日期。
- PE 缺失、PE ≤ 0 或国债数据缺失时不计算该日利差；**不做前向填充，不做插值**。

```
percentile = 100 ×（历史小于当前值的数量 + 0.5 × 历史等于当前值的数量）÷ 有效样本数量
```

- 默认窗口为过去 5 年，只使用**严格早于当前数据日期**的有效样本；使用未做显示舍入的数值计算。
- 有效样本不足 252 个时不显示百分位，标注「样本不足」。
- 历史不足 5 年时标注「可用历史百分位」，不称为「5年百分位」。
- 该百分位是**股债利差的百分位**，不是 PE 的百分位。

### A股情绪模块的分位口径（macroboard/sentiment）

排名公式与上文**完全相同**（严格早于当前数据日期 + 中位秩），差别只在窗口：

| | 股债利差百分位（上文） | 情绪模块 |
| --- | --- | --- |
| 窗口 | 过去 5 个自然年（`relativedelta`） | 过去 N 个交易日，默认 252，可逐分量配置 |
| 最小样本 | 252 个有效样本 | 默认 `ceil(window × 120/252)`（252 -> 120）；要满窗须显式配置 `min_periods=window` |
| 样本范围 | 严格早于当前数据日期 | 严格早于当前数据日期（相同） |
| 并列值 | `0.5 × 等于` 的中位秩 | 中位秩（相同） |

因此：

- 情绪模块的分位**不得**称为「5 年百分位」，只能称「N 日滚动分位」；
- 默认 `min_periods=120` 下：252 尺度分量自第 121 个交易日有值（量比分量因先做 20 日均量，
  自第 140 个交易日有值）；综合情绪指数自第 121 个交易日起可用（初期可能只覆盖部分分量，
  覆盖率与缺失清单逐日输出）；综合情绪自身的 252 日分位（对已被预热一次的综合指数再取分位）
  自第 241 个交易日有值，即**约一年数据即可完整跑通**，不需要回补多年历史；
- 样本未满窗口时，页面必须标「可用历史百分位」，不得标「252 日分位」；
- 分量尺度（含多尺度加权）与 `min_periods` 由配置决定，页面需逐指标展示当前生效窗口。

## 五、页面曲线与显示粒度

页面按观察周期分区块，**短线在上、长线在下**，每个区块各自带「时间范围」与
「曲线粒度」控件，互不联动：

- 短线指标：A股市场情绪（情绪曲线与四象限，默认 1 年）；
- 短线指标：A股市场宽度（沪深A股上涨家数占比、沪深300近20个交易日涨跌幅，默认 1 个月）
  ——**当前暂时下线**，由 `app.py::SHOW_BREADTH_BLOCK` 控制；数据仍在采集，恢复开关即回到页面；
- 长线指标：美国10年期、中债10年期、美元兑人民币（在岸即期）、现货黄金，以及沪深300股债利差（默认 5 年）。

即六类指标各画一条变化曲线，另有股债利差曲线。

### 为什么不用「近密远疏」做默认

在线性时间轴上按「近密远疏」抽稀，近端日度点会被压缩到图形右侧很窄的一段
（近 90 天只占 5 年视图宽度的 5%），视觉上并不比统一周线更清楚，反而让线条
疏密不均。真正能让「近密远疏」在视觉上生效需要对数时间轴，但那样斜率不可比，
不适合作为默认观察工具。

因此默认改为**一个视图内只使用一种分辨率**，让时间轴与数据密度始终匹配：

| 时间范围 | 自动分辨率 | 典型点数 |
| --- | --- | --- |
| 1 个月 | 日线 | 约 21 |
| 3 个月 | 日线 | 约 63 |
| 1 年 | 日线 | 约 250 |
| 3 年 | 周线 | 约 156 |
| 5 年 / 全部 | 月线 | 约 60 |

### 可选粒度

页面提供「曲线粒度」选择：自动（按范围，默认）、日线、周线、月线、近密远疏、原始日度。

- 日线 / 周线 / 月线：整个视图统一粒度，时间轴与点距一致。
- 近密远疏：保留极端细节时使用，图上会用虚线标出「90天：日线→周线」「1年：周线→月线」
  「3年：月线→季线」的切换位置，避免读者误判密度变化。
- 原始日度：不做任何抽稀（5 年约 1250 点，线条较重）。

所有模式都**只保留区间内最后一个真实观测**，不做平均、不插值，图上每个点都能对回
来源原始数值。页面每张图下方显示「最新值 + 粒度 + 显示点数/切片点数」。

抽稀只影响曲线绘制；**股债利差百分位始终用全部有效样本计算**，与显示粒度无关。

## 六、访问统计（页面人次，非行情数据）

页面底部的「访问统计」是本项目自带的轻量计数，**不是行情指标**。来源是**本机 SQLite 文件**
（默认 `data/visits.sqlite3`，可用环境变量 `MACROBOARD_VISIT_DB` 指向别处）：不联网、
不使用第三方统计服务、不向任何外部服务器发送任何数据。

| 存储字段 | 类型 | 说明 |
| --- | --- | --- |
| `visits.at` | TEXT | 访问时刻，UTC ISO8601（如 `2026-09-20T02:30:00Z`） |
| `visits.day` | TEXT | 该次访问所属自然日，按北京时间（Asia/Shanghai）划分 |
| `visits.visitor` | TEXT | 去重用的访客指纹，见下 |
| `visits.ip` | TEXT | 客户端 IP 原文（2026-09-20 起记录，页面不显示）；本机/回环访问为 NULL，补列之前的历史行为空 |
| `meta.key` / `meta.value` | TEXT | 目前只存指纹盐 `visitor_hash_salt` |

**访客指纹** = `SHA-256(随机盐 + 客户端 IP + User-Agent)` 的前 16 位十六进制字符，
只用于去重；盐随机生成后保存在同一个统计库的 `meta` 表里，不上传、不导出。
指纹相同只说明「同一 IP + 同一浏览器」，不是身份识别，也不用于登录、鉴权或风控。
**User-Agent 只以指纹形式参与，不保存原文**。

**客户端 IP 会以原文保存在 `visits.ip`**（2026-09-20 起），供后台按来源核对，
页面暂不展示。统计库只在本机、文件权限 `600`、已被 `.gitignore` 忽略，
但 IP 会一直留存且没有自动过期：删除 `data/visits.sqlite3` 即清除全部访问记录（含 IP）。
客户端 IP 取自 Streamlit 的会话上下文（`st.context.ip_address`）；本机/回环访问时该值为
`None`，`ip` 记 NULL，指纹按 `local` 参与计算。

### 统计口径

- **访问人次**：一次页面会话（打开或刷新页面）计 1 人次。Streamlit 每次交互都会重跑脚本，
  页面用会话状态（`st.session_state`）保证同一次会话只记录一次，切换时间范围、
  缩放图表等操作不会重复计数。
- **独立访客**：「今日」「近 7 日」「累计」各自在对应区间内按指纹去重，不做跨区间推算。
- **访客 IP**：每条记录同时保存客户端 IP（`visits.ip`），页面不显示；需要时可直接查库，例如
  `SELECT ip, COUNT(*) FROM visits WHERE day >= '2026-09-01' GROUP BY ip ORDER BY 2 DESC;`
- 明细表只列出实际有访问的日期，**不补零、不外推、不估计**。
- 统计库与行情库分开：页面记录访问计数不会改动 `data/macroboard.sqlite3` 中的任何观测值；
  删除 `data/visits.sqlite3` 即清空统计（页面回到 0，不从别处推断）。
- 关闭统计：环境变量 `MACROBOARD_VISIT_LOG=0`，页面显示「访问统计：已关闭」。

### 已知限制

| 项目 | 说明 |
| --- | --- |
| 会话重建 | WebSocket 断开、浏览器休眠唤醒或服务重启后 Streamlit 会新建会话，同一个人可能被计成多次 |
| 访客识别 | 没有 cookie 也没有登录：同一人换浏览器或换设备会记为不同访客，同一 IP + 同一浏览器会记为同一访客；同一台机器分别用 `127.0.0.1` 与局域网 IP 打开也会算成两个访客 |
| 反向代理 | 经反向代理部署时，`st.context.ip_address` 反映的是 Streamlit 看到的连接来源，不保证是终端访客的真实 IP |
| 历史易失 | 只存明细、不做独立备份：删除统计文件或磁盘故障即丢失历史记录 |
| IP 留存 | 客户端 IP 原文会一直留在统计库里，没有自动清理或脱敏；删除统计文件即清除全部记录 |
